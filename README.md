# Pig Dice Site

Mini website for the *Pig Dice* Android application  
(CIS 218 – About / Splash Screen Assignment)

This website contains two public pages used in the Pig Dice Android app:

- **About Page:** Basic information about the developer and the app.  
- **Support Page:** A working contact form (using Formspree) to send questions to the developer.

## 🌐 Live Pages

- [About Page](https://silverphantomspokane.github.io/pig-dice-site/about.html)  
- [Support Page](https://silverphantomspokane.github.io/pig-dice-site/support.html)

## 💡 Technologies Used
- HTML5 & CSS3  
- JavaScript
- GitHub Pages (for hosting)
